# SamAuction — 옥션&액션

1:1 과외를 월간 경매로 연결하는 웹 서비스입니다.
선생님은 수업 상품을 등록하고, 학생·보호자는 입찰하며, 월말 자동 낙찰과 모의 결제·정산까지 하나의 상태 기반 프로세스로 이어집니다.

## 핵심 규칙

- **경매 사이클**: 매월 1일 00:00 ~ 말일 23:59:59 (KST)
- **수업 사이클**: 낙찰 다음 달, 주 1회 60분 × 4회
- **입찰 단위**: 시간당 수업료(원)
- **결제 총액**: 낙찰 시간당 가격 × 4회
- **입찰 방식**
  1. `SEALED_MAX` — 비공개 최대가(2가격 규칙)
  2. `FIRST_COME` — 선착순 즉시 낙찰
  3. `DUTCH` — 1시간 단위 하락 경매
- **정산**: 수업 완료 후 플랫폼 수수료 10% 차감, 에스크로 해제

## 현재 포함된 내용

- `src/domain/auction-engine.mjs` — 프레임워크/의존성 없는 경매 도메인 엔진
  - KST 월간 사이클 계산
  - 비공개 최대가 평가(동점·차순위 포함)
  - 선착순/하락 가격 검증
  - 입찰 자격·지역·보호자 동의 검증
  - 상태 전이표, 월 수업료·수수료 계산
- `sam_logic.md.txt` — 최초 요구사항 원문

프론트엔드 프로토타입(모의 결제 포함)은 이 저장소에 순차적으로 추가됩니다.
