# 👩‍🏫 샘옥션클래스 (SamAuction) 🎓

**서비스명: 샘옥션클래스** — 1:1 방문교육·1:1 화상교육·1:n 그룹 교육을 **월간 경매**로 연결하는 웹 서비스 프로토타입입니다.
선생님은 한 달 수업권을 등록하고, 학생·보호자는 입찰합니다. 월말에 자동으로 낙찰·결제되고,
수업 완료 후 플랫폼 수수료를 제외한 금액이 선생님께 정산됩니다.

> **바로 보기**: <https://narayo20.github.io/SamAuction/>

> 모든 결제는 **모의 결제**입니다. 실제 카드 승인이나 금액 청구는 발생하지 않습니다.
> 카드 번호 전체는 저장하지 않고 브랜드와 마지막 4자리만 브라우저 메모리에 보관합니다.

## 핵심 규칙

- **경매 사이클**: 매월 1일 00:00 ~ 말일 23:59:59 (KST)
- **수업 사이클**: 낙찰 다음 달, 주 1회 60분 × 4회
- **입찰 단위**: 시간당 수업료(원)
- **결제 총액**: 낙찰 시간당 가격 × 4회
- **플랫폼 수수료**: 결제 총액의 10%
- **에스크로**: 결제 즉시 보관, 수업 완료 후 운영자 정산 시 선생님께 지급

### 수업 방식

선생님이 등록할 때 고르고, 학생·학부모는 목록·상세·입찰 모달에서 같은 라벨로 확인합니다.

| 방식 | 코드 | 설명 | 추가 입력 |
| --- | --- | --- | --- |
| **1:1 방문교육** | `VISIT` | 선생님이 학생 집으로 방문하는 1:1 수업 | 가능 지역 1개 이상 **필수** |
| **1:1 화상교육** | `ONLINE` | 지역과 무관하게 화상으로 진행하는 1:1 수업 | 없음 (지역 무관) |
| **1:1 방문·화상** | `BOTH` | 방문과 화상을 모두 제공하는 1:1 수업 | 가능 지역 선택 |
| **1:n 그룹 교육** | `GROUP` | 정원 2~8명이 함께 듣는 그룹 수업 | **그룹 정원(2~8명)** 필수 |

- 홈 경매 목록에 **수업 방식 필터**가 추가되어 1:1 방문교육·1:1 화상교육·1:1 방문·화상·1:n 그룹 교육별로 볼 수 있습니다.
- 그룹 경매는 그룹 정원 중 **1자리**를 낙찰하는 프로토타입입니다. 다자리 동시 낙찰은 설계 메모의 확장 항목입니다.

### 입찰 방식

| 방식 | 규칙 |
| --- | --- |
| **비공개 최대가** (`SEALED_MAX`) | 보호자가 최대 시간당 입찰가를 비공개로 제출합니다. 월말에 최고가 입찰자가 낙찰되고, 실제 결제가는 `max(시작가, 차순위 최고가 + 최소 입찰 단위)`를 최고가로 cap 한 금액입니다. 동점이면 먼저 입찰한 사람이 우선합니다. 낙찰자 결제 실패 시 차순위 후보로 자동 재낙찰합니다. |
| **선착순** (`FIRST_COME`) | 즉시 낙찰가에 입찰하고 결제가 승인된 순간 경매가 종료됩니다. 결제 실패 시 경매는 다시 열립니다. |
| **하락 경매** (`DUTCH`) | 등록 시점부터 1시간마다 가격이 내려갑니다. 현재가에 입찰·결제가 성공하면 즉시 낙찰됩니다. 최저가에 도달하면 말일까지 최저가로 유지됩니다. |

### 상태 흐름

```text
경매: SCHEDULED → LIVE → CLOSING → AWARD_PENDING → AWARDED
                                              ↘ UNSOLD

주문: PAID → CONFIRMED → COMPLETED → SETTLED
                        ↘ REFUNDED (운영자 환불)
```

## 구현된 기능

- **홈**: 이번 달 경매 목록, 과목·수업 방식·입찰 방식·지역·정렬·검색 필터, 월간 캘린더, 다음 달 예정 경매
- **경매 상세**: 선생님 프로필, 숏폼 영상(프리미엄), 수업 소개, 월간 플랜, 입찰 방식 설명, 실시간 가격·카운트다운, 경매 기록
- **입찰**: 비공개 최대가 등록·수정, 선착순 즉시 낙찰, 하락 경매 현재가 낙찰, 보호자 동의, 자녀 선택, 결제수단 선택
- **모의 결제**: 카드 등록·검증, 승인 성공/실패, 처리 중 화면, 실패 후 재시도, 영수증
- **자동 낙찰**: 월말 마감, 비공개 최대가 2가격 평가, 결제 실패 시 차순위 자동 낙찰, 유찰 처리
- **선생님 스튜디오**: 경매별 입찰·낙찰 현황, 받은 입찰·정산 예정·누적 정산, 새 경매 등록(수업 방식 4종·입찰 방식 3종·그룹 정원), 프리미엄 구독·끌올
- **학생·학부모 데스크**: 자녀 프로필(프리미엄 최대 5명), 카드 관리, 내 입찰, 수업·결제·일정 확인
- **주문 상세**: 결제 정보, 에스크로 상태, 수업 일정 확정, 수업 완료, 영수증, 타임라인
- **운영 콘솔**: 전체 경매·결제·정산 모니터, 강제 마감, 정산·환불, 이벤트 로그
- **데모 도구**: 시간 이동(+1시간/+1일/월말 10초 전), 가상 경쟁 입찰, 데모 초기화
- **반응형 UI**: 모바일 1열 레이아웃, 하단 시트형 모달

| 김민지 학부모 | 학부모 | 프리미엄 학생, 자녀 2명, 성공/실패 카드 보유 |
| 이정은 학부모 | 학부모 | 일반 학생 |
| 운영자 | 관리자 | 전체 운영 콘솔 |

### 테스트 카드

| 카드 번호 | 결과 |
| --- | --- |
| `4242 4242 4242 4242` | 승인 성공 |
| `4000 0000 0000 0002` | 승인 실패 (의도된 거절) |
| 그 외 16자리 + 미래 유효기간 | 모의 승인 성공 |

시드 카드 `•••• 0002`는 실패 카드로 등록되어 있어 실패·재시도 흐름을 바로 확인할 수 있습니다.

## 실행

Node.js 20 이상이면 별도 설치 없이 실행할 수 있습니다.

```bash
npm start
# 또는
node server.mjs
```

- 기본 주소: <http://127.0.0.1:4173>
- 포트 변경: `PORT=4174 node server.mjs` (PowerShell: `$env:PORT=4174; node server.mjs`)

정적 서버는 `index.html`과 `assets/`, `src/` 파일만 제공합니다.
데모 데이터는 브라우저 `localStorage`에 저장되며, **데모 초기화**로 언제든 시드 상태로 되돌릴 수 있습니다.

## 테스트

```bash
node --test test/
```

- `test/store-flow.test.mjs` — 비공개 최대가 월말 자동 낙찰, 선착순 즉시 낙찰, 하락 낙찰, 결제 실패 시 차순위 낙찰, 프리미엄 끌올, 경매 등록(수업 방식·그룹 정원 포함)

## 데모 시나리오

1. **비공개 최대가**: `김민지` 계정 → 경매 `중2 수학...` → 최대가 수정 → 우측 상단 `데모` → `월말 10초 전` → 자동 낙찰·에스크로 결제 확인
2. **선착순**: `영어 문법·독해...` → 결제하고 낙찰받기 → `4242` 카드로 즉시 낙찰 → 영수증
3. **선착순 실패·재시도**: `파이썬 첫걸음...` → `•••• 0002` 카드 선택 → 승인 거절 → `다시 시도` → 성공 카드로 낙찰
4. **하락 경매**: `국어 독해력...` → `+1시간`으로 가격 하락 확인 → 현재가로 낙찰
5. **차순위 낙찰**: 비공개 최대가 경매에서 최고가 입찰자의 카드를 실패 카드로 바꾼 뒤 `지금 마감` → 차순위 자동 낙찰
6. **정산**: 학부모 계정에서 수업 완료 → 운영자 계정 → `정산` → 에스크로 `RELEASED` 확인
7. **환불**: 운영자 계정 → 주문 `환불` → 에스크로 `REFUNDED` 확인

## 설계 메모

- 도메인 엔진은 브라우저와 Node 테스트에서 동일하게 사용하는 **의존성 없는 ES 모듈**입니다.
- 경매 사이클·가격 계산·입찰 검증·상태 전이는 `src/domain/auction-engine.mjs`에 모아 두고, `store.js`는 저장·결제·화면용 데이터 조합을 담당합니다.
- 프로토타입은 서버 없이 동작하도록 `localStorage`를 사용합니다. 실제 서비스에서는 아래가 필요합니다.
  - 서버 측 스케줄러(월말 마감·하락 가격 틱)
  - 인증·권한, 개인정보 암호화, PG 웹훅 검증
  - 입찰 동시성 제어와 감사 로그
  - 에스크로·정산 원장과 세금계산서
- `GROUP` 수업은 프로토타입에서 **정원 정보를 표시하고 1자리만 낙찰**합니다. 실제 그룹 서비스에서는 정원만큼 다자리 낙찰·개별 결제가 필요합니다.
- 화면의 모든 금액·날짜는 한국 시간(KST) 기준으로 표시됩니다.
